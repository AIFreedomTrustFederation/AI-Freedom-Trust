# AI Freedom Trust UNIX Manual Manual

This directory contains the UNIX-style manual source for this repository.

Manual source belongs to this repo. PDF and publication builds belong to BookSmith.

**Manual source coverage.** The [manual manifest](../../.aift/manual.json) lists ten category slots (`man0`–`man9`), but checked-in authored pages currently exist only under [`source/man0/`](source/man0/) and [`source/man7/`](source/man7/). The other categories are reserved index entries, not completed manual chapters. `manualSource: ready` is a declared source state, not evidence of complete category coverage, a successful BookSmith PDF build, or publication; the builder's `manual.build.pdf` capability, `pdfBuild`, and `webPublish` remain `planned`.
